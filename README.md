# WATT – Arbeitszeiterfassung für Lehrkräfte

Kostenlose Android-App (Beta) zur Selbstaufzeichnung der Arbeitszeit verbeamteter Lehrkräfte, lokal auf dem Gerät, ohne Konto und Server.

Tester:in werden: https://aves83.github.io/watt_public/

Dieses Repository enthält die öffentlichen Begleitdateien zu WATT: die Testseite, Informationsmaterial (`info/`), Datenschutzerklärung und Nutzungsbedingungen (`doc/`) sowie die Schemas des Datenformats (`schema/`). WATT selbst ist nicht quelloffen.
