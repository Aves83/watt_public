# WATT – Arbeitszeiterfassung für Lehrkräfte

Kostenlose Android-App zur Selbstaufzeichnung der Arbeitszeit verbeamteter Lehrkräfte, lokal auf dem Gerät, ohne Konto und Server.

Im Play Store: https://play.google.com/store/apps/details?id=de.achim.watt · Webseite: https://aves83.github.io/watt_public/

Dieses Repository enthält die öffentlichen Begleitdateien zu WATT: die Webseite, Informationsmaterial (`info/`), Datenschutzerklärung und Nutzungsbedingungen (`doc/`) sowie die Schemas des Datenformats (`schema/`). WATT selbst ist nicht quelloffen.
